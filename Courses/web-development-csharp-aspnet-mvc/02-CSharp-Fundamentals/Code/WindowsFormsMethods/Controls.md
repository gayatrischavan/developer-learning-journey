# Windows Forms Controls

## Controls Used

| Control | Purpose |
|----------|----------|
| Label | Display text |
| TextBox | User input |
| Button | Execute event |
| GroupBox | Group RadioButtons |
| RadioButton | User selection |

---

# Form Layout

```
+--------------------------------+

Name

[ TextBox1 ]

Copied Text

[ TextBox2 ]

( ) Male

( ) Female

( ) Other

[ Execute ]

Label

+--------------------------------+
```

---

# Control Flow

```
Button Click

↓

Method Called

↓

Control Updated

↓

User Sees Result
```
