# Windows Forms Methods Examples

## Overview

This folder contains the Windows Forms examples demonstrated in the Udemy course for learning **Methods in C#**.

These examples show how methods help organize code and make applications reusable.

---

# Learning Objectives

After completing these examples, you will understand:

- Creating methods
- Calling methods
- Passing parameters
- Using methods with controls
- Updating UI using methods
- Code reusability

---

# Examples Included

## Example 1

Hide Radio Buttons

Method

```csharp
HideRadioButtons();
```

---

## Example 2

Clear TextBoxes

Method

```csharp
ClearAllText();
```

---

## Example 3

Fill Second TextBox

Method

```csharp
FillTextBox(string text);
```

---

## Example 4

Display Age

Method

```csharp
SetNumber(int age);
```
