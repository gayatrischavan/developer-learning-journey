# Using Random Class - Code Examples

This folder contains practical examples related to **Using the Random Class in C#**, matching [Notes/14-Using-Random-Class.md](../../../Notes/14-Using-Random-Class.md).

## Learning Objectives

After completing these examples, you will be able to:

- Create and reuse a single `Random` object
- Generate a non-negative random integer with `Next()`
- Generate an integer within a specific range with `Next(min, max)`
- Correctly explain the inclusive/exclusive range rules
- Generate a random `double` with `NextDouble()`
- Fill a byte array with random values using `NextBytes()`
- Build a random character/string/password using index-based selection
- Understand why the password example is educational only, not secure

## Important Rules

```text
Next(min, max)
→ min inclusive
→ max exclusive

NextDouble()
→ 0.0 inclusive
→ 1.0 exclusive
```

`Random` produces **pseudo-random** values — numbers that look random but are generated by a deterministic algorithm. A single `Random` object should be created once and reused for multiple calls, rather than creating a new one for every value.

---

## ⚠️ Security Warning

`RandomPassword.cs` is a **learning example only**, meant to practice `Random` and string building. It is **not** cryptographically secure and must not be used for real authentication, tokens, or production passwords. Security-sensitive password/token generation should use a proper cryptographic API (such as `System.Security.Cryptography`), not ordinary `System.Random`.

## How to Run the Examples

1. Open this folder as (or add it to) a C# Console Application project.
2. Set `Program.cs` as the startup file.
3. Run the project (`F5` in Visual Studio, or `dotnet run`).
4. Read the console output alongside each file — remember that random values differ on every run.
